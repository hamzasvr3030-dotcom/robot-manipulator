🦾 Örnek kol

3 eklemli düzlemsel kol (RRR)

Düşey düzlemde çalışır, yerçekimi aşağı yönde etki eder. Omuz, dirsek ve bilek eklemleri var.

L₁ = 0.30 · L₂ = 0.25 · L₃ = 0.10 m

Maksimum erişim 0.65 m. Eklem sınırları: q₁ ±180°, q₂ ve q₃ ±150°.

Yük kapasitesi 0.5 kg

Tutucu dahil. Bu yük için eklem 1 yaklaşık 21.5 N·m tork istiyor (Konu 5).

Python + URDF

Aynı kol hem kod/robot_kol.py'de hem de ROS için urdf/rrr_kol.urdf'de tanımlı.

▶️ Kodları çalıştır

Yalnızca numpy + matplotlib gerekir
git clone https://github.com/hamzasvr3030-dotcom/robot-manipulator
cd robot-manipulator
pip install -r requirements.txt
cd kod
python k02_duz_kinematik.py   # sonuç ekrana yazılır, grafik gorseller/ klasörüne kaydedilir
